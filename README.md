# FUTURE_PE_01
AI Website Copy Generator using Prompt Engineering for The Chocolate Room India.
**Business:** The Chocolate Room India
**Tool used:** Claude (claude.ai)

## Business chosen
The Chocolate Room India — a premium chocolate dessert
café chain operating across India.

## Prompt logic
A master system prompt establishes brand tone, audience,
and goals. Four task-specific prompts then generate each
section: homepage, services, CTAs, and tone variations.
Prompts are reusable — swap the business name to use
for any new client.

## Folder structure
- /prompts — all structured prompts used
- /outputs — final AI-generated website copy
  
## Files
| File | Purpose |
|---|---|
| prompts/00_master_system_prompt.md | Base context for all prompts |
| prompts/01_homepage_prompt.md | Homepage hero copy |
| prompts/02_services_prompt.md | Service descriptions |
| prompts/03_cta_prompt.md | CTA sections |
| prompts/04_tone_adaptation_prompt.md | Tone variations |
| outputs/chocolate_room_website_copy.md | Full generated copy |
