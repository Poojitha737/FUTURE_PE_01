## 📋 PROMPT FRAMEWORK (Structured & Reusable)

### Master System Prompt (use at start of every session)
```
You are an expert conversion copywriter for a premium dessert café brand.
Business: The Chocolate Room India
Type: Upscale chocolate-themed café chain with dine-in, takeaway, and franchise model
Tone: Warm, indulgent, slightly playful — like talking to a friend who loves good food
Audience: Urban millennials, couples, families, and dessert lovers aged 18–40
Goal: Write website copy that converts visitors into café walk-ins, online orders, or franchise inquiries.
Always write in second-person ("you", "your"). Keep sentences short. Every section must end with a clear next step.
```

---

### Prompt 1 — Homepage Hero Copy
```
Using the master system prompt above, write homepage hero copy for The Chocolate Room India.
Include:
- A punchy headline (max 8 words) that captures the brand's indulgent identity
- A sub-headline (1–2 lines) that tells visitors who this is for and what they'll experience
- A 2-sentence intro paragraph below the hero image
- Two CTA buttons: one for "Find a Café Near You" and one for "Explore Our Menu"
Tone: Warm, inviting, premium but not intimidating.
```

---

### Prompt 2 — Services / Menu Page Copy
```
Write the Services/Menu page copy for The Chocolate Room India.
Cover these 5 product categories:
1. Hot Chocolate Drinks
2. Waffles & Crepes
3. Chocolate Fondue
4. Cakes & Brownies
5. Shakes & Cold Beverages
For each category write:
- A category headline (5–6 words, sensory language)
- A 2–3 sentence description focusing on taste and experience
- One "Why choose this" line (trust/quality signal)
Tone: Indulgent, descriptive, mouthwatering.
```

---

### Prompt 3 — CTA Sections
```
Write 3 CTA sections for The Chocolate Room India website:
1. Visit CTA — for the homepage footer, encouraging in-store visit. Include urgency or occasion hook.
2. Franchise CTA — for a franchise inquiry page. Professional and aspirational tone.
3. Order CTA — for an online order page. Fast, friendly, action-focused.
Each CTA must have: a headline, 1–2 lines of supporting copy, and a button label.
```

---

### Prompt 4 — Tone Adaptation Test
```
Rewrite the homepage hero headline and sub-headline from Prompt 1 in three tones:
1. Playful & Fun (for social media use)
2. Professional & Premium (for franchise pitch decks)
3. Romantic & Intimate (for Valentine's Day seasonal campaign)
Keep the core value proposition the same. Only change tone and word choices.
```
